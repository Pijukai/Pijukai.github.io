Objective
Give surgical robot world models a way to be measured, so their development can be guided by clear evaluations.
Status
Work in progress: the evaluation suite is being applied to NVIDIA Cosmos 3.

The project

I designed an evaluation suite for surgical robot world models, covering action faithfulness and tissue-biomechanical plausibility, to guide model development. It is applied to NVIDIA Cosmos 3, under the supervision of an NVIDIA ML Engineer.

This project is still ongoing. More details and results will be added here as the work progresses.
